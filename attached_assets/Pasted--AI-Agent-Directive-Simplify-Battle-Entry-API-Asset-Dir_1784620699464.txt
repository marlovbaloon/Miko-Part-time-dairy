# 🤖 AI Agent Directive: Simplify Battle Entry API & Asset Directory Refactoring

## 🎯 Primary Goal
Refactor the battle system initialization to provide a clean, high-level API (`battle.start(enemy_id)`) meant for seamless cutscene-to-battle transitions. Re-organize directory naming conventions (`enemies` -> `youkai`) and prepare `battle.lua` to interface with `states_manager.lua` without immediately triggering active scene transitions yet.

---

## 🛠️ Step-by-Step Task Execution Protocol

### Step 1: Directory & Asset Path Renaming
* **Action:** Rename directory paths to align with the domain model (`youkai`).
* **Path Changes:**
  1. Move/Rename image directory:
     * **Old:** `Miko Part-time Diary/assets/images/enemies/`
     * **New:** `Miko Part-time Diary/assets/images/youkai/`
  2. Data/Dialogue directory check:
     * Ensure dialogue files are targeted at `Miko Part-time Diary/data/dialogue/youkai/`.
  3. Update references inside `enemy_loader.lua` and `kudagitsune.lua` to point to the new asset paths (`assets/images/youkai/...`).

---

### Step 2: Implement Simplified `battle.start(enemy_id)` Entry Point
* **Action:** Refactor `Miko Part-time Diary/source/gameplay/battle_system/battle.lua`.
* **Tasks for AI Agent:**
  * Create/Export a clean public entry function: `battle.start(enemy_id)`.
  * Inside `battle.start(enemy_id)`:
    1. Call `enemy_loader.load(enemy_id)` to fetch enemy blueprint and preload sprite from `assets/images/youkai/`.
    2. Invoke `enemy_loader.inject_to_battle(enemy_data, state, structs)` to initialize battle state, stats, ACT commands, and dialogue queues.
    3. Reset battle flags (player HP, turn counter, soul position, box dimensions, bullet pools).
    4. Set internal battle state to active (`state.is_active = true` or equivalent).
  * Deprecate/Simplify complex signatures like `battle.load(saveData, ...)` so cutscene triggers only need to pass `enemy_id`.

---

### Step 3: Require `states_manager.lua` in `battle.lua`
* **Action:** Connect module dependencies in `Miko Part-time Diary/source/gameplay/battle_system/battle.lua`.
* **Tasks for AI Agent:**
  * Add `local states_manager = require("source.states_manager")` (or correct relative path) at the top of `battle.lua`.
  * **Constraint:** Do NOT trigger scene switching or activate state transitions in game logic yet. Keep it purely required as an available dependency for future state handoffs (e.g., exiting battle back to narrative state).

---

### Step 4: Verify Enemy System & Asset Loader
* **Action:** Validate `enemy_loader.lua` logic with updated pathing.
* **Tasks for AI Agent:**
  * Ensure `enemy_loader.lua` constructs sprite paths pointing to `assets/images/youkai/<enemy_id>.png`.
  * Verify dialogue loading looks into `data/dialogue/youkai/<enemy_id>.lua` (or json/text if mapped).
  * Ensure `kudagitsune.lua` sprite field reflects `assets/images/youkai/kudagitsune.png`.

---

## 🎯 Verification Criteria
1. **Simple Trigger:** Executing `battle.start("kudagitsune")` successfully sets up and starts the battle without needing external save data parameters.
2. **Clean Asset Resolution:** Enemy sprites load without errors from `assets/images/youkai/`.
3. **Dependency Ready:** `states_manager.lua` is required inside `battle.lua` without causing circular dependency issues or premature state changes during runtime.
